# Trabalha Paulista (versão demonstrativa)

Plataforma de emprego, capacitação e empreendedorismo local em Paulista–PE. Projeto acadêmico.

## Como executar
1. Abra a pasta no VS Code.
2. Use a extensão Live Server ("Go Live") ou abra `index.html` no navegador.
3. É necessário internet: React e htm são carregados por CDN.

## Arquivos
- `index.html`, `styles.css`, `app.js`

## Limitações
- Dados fictícios; autenticação demonstrativa, sem segurança real.
- Contas, desativação e exclusão valem só na memória da aba.
